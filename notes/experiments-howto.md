# フェーズ1 実験の進め方

実験の一覧と共通ルールは `notes/experiments-plan.md` にある。
このファイルは、1グループを実際に回すときの手順と、予想の書き方をまとめたもの。

---

## 手順（1グループごと）

1. **定義ファイルを開く**
   `experiments/definitions/` の下にグループごとのファイルがある（A なら `a_numbers_and_labels.py`）。
   state、質問文、予想を書く `PREDICTIONS` が1ファイルにまとまっている。
2. **ケースごとに state と質問文を読む**
   `PREDICTIONS` のキー（`exp1_aoi_raw` など）と、同じ名前のケースの state を見比べる。
3. **`PREDICTIONS` に予想を書く**
   書き方は下の「予想の書き方」を参照。空のケースが残っていると `run.py` は実行を止める。
4. **実行する**
   ```bash
   uv run python experiments/run.py a_numbers_and_labels
   ```
   引数はグループのファイル名（拡張子なし）。
5. **結果を見る**
   `experiments/results/` に JSON と Markdown で記録される。Markdown に予想と結果が並ぶ。
6. **予想と違ったものを notes/ に書く**
   なぜ違ったと思うかを一言添える。ポートフォリオで Jev の得手不得手を語る材料になる。

**一気に全部やらず、グループごとに回す。**
A の予想 → A を実行 → 結果を見る → B の予想、の順。前のグループの結果を見てから次の予想を書くと、ずれ方の傾向がつかめる。1回あたり30分〜1時間で区切れる。

---

## 予想の書き方

`PREDICTIONS` の値は文字列。**見込みの数値＋そう思う理由を一言**で書く。数値だけだと、後で結果と並べたときになぜそう読んだかが追えない。

```python
"exp1_sample_raw": "0.6前後。数値の比較は苦手とあったので、正解でも言い切らないと思う",
"exp1_sample_label": "0.95以上。ラベルに答えがほぼ書いてあるので迷わないはず",
```

- **数値は幅を持たせてよい。** 「0.8前後」「0.9以上」で十分。ぴったり当てるのが目的ではない。
- **理由は短くてよい。** 後で思い出せれば足りる。
- **1つのケースで複数の質問を聞いている場合は、それぞれ書く。**
  ```python
  "exp2_sample_raw": "big_drop=0.4前後、move_size=1.2前後。（理由）",
  ```

### 返ってくる値の形

- **Noul** → `noul`（0〜1の「はい」である確率）のみ。confidence は付かない。
  0.9 は「9割方はい」、0.5 は「どちらとも言えない」。
- **Score** → `score`（段階の間の値）と `confidence`。段階が3つなら 0〜2 の範囲。
  値を細かく読みすぎない。閾値を超えたかの判定に使う程度にとどめる（jaggedness より）。
- **Choice** → `choice`（選ばれた選択肢）、各選択肢の確率、`confidence`。

## A. 数値とラベル（定義：`a_numbers_and_labels.py`）

言語は日本語で統一（state のキーも値も質問文も）。英語との差は実験19で別に測る。

### 実験1：数値の比較（6ケース）
- 質問はすべて同じ：「25日移動平均は75日移動平均より大きい」（Noul）
- 変えるのは state だけ：生の数値を渡す／トレンドのラベルを渡す。3銘柄 × 2通り。
- **見どころ**：千鳥化学は 880.51 対 879.97 の僅差。差が大きい銘柄と比べて、数値比較でどこまで踏ん張れるか。
- 公式は「Jev は数値を量としてではなくテキストとして読む」としているが、どれくらい苦手かは書いていない。そこを確かめる。

### 実験2：境目の近く
- 前日比 -2.9% と -3.1% を生で渡して「大幅下落か」（Noul）。
- Jev の「大幅」の感覚が、自分の決めたい境目とずれるかを見る。

### 実験4：数値を渡したときの confidence
- 値動きの大きさを Score でも聞き、その confidence を、生の数値とラベルで比べる。
- 実験2と state が同じなので、Noul と Score を1リクエストにまとめてある。

### 実験3：出来高の表し方（6ケース）
- 出来高を「株数」「平均との比」「ラベル」の3通りで渡す。
- 行田システム（3.1倍、明らかに多い）と白馬製薬（1.01倍、ほぼ平常）の2銘柄。
- 同じ事実でも、どの表し方が一番安定するか。
