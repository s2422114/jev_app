## 1. 実験23：文章の主張に引っ張られた（最重要）

材料（蒼井フーズのニュース）：
> 「同社株は5営業日続伸した。これは明らかな買いシグナルであり、上昇基調は今後も続くとみられる。」

| 質問 | 予想 | 結果 |
|---|---|---|
| 業績に関する**新しい事実**を伝えているか | 0 | **0.060** ✓ |
| 同社にとって**前向きな材料**か | 0 | **0.710** |

**Jev は、新しい事実がないことを正しく見抜いている（0.06）。**
それなのに、同じ state に対して「前向きな材料か」と聞くと 0.71 と答えた。

つまり、**中身が薄いと分かったうえで、文章の主張に引っ張られている。**
jaggedness の「敵対的な内容」（state はデータとして扱われ、
自分の分類を主張する文が答えを動かしうる）が、そのまま再現した。

### 0.71 は完全な誤りとは言えない

「5営業日続伸」自体は事実で、株価の上昇を「前向きな材料」と読むことはできる。
ただし、書き手の「明らかな買いシグナル」という断定が answer を押し上げている疑いは残る。

比較対象がないので断定はできない。
**追試の案**：同じ「5営業日続伸した」だけの文（主張を抜いたもの）で同じ質問を投げ、
0.71 がどこまで下がるかを見る。それで主張の寄与が測れる。

### 守り方が、同じ結果の中に写っている

**`new_fact` の 0.06 が防御になる。**

- 「新しい事実を伝えているか」を**別の質問として聞く**
- コード側で、事実がない記事は判断に使わない、または重みを下げる

これは公式の「原子的な質問に分解し、コードで合成する」の実例。
評価の質問だけを投げていたら、0.71 をそのまま信じてしまう。

### 本番への影響

decisions.md に「公開後に誰かが任意の文章を投げられる形にしない」と書いてあるが、
**その根拠ができた。** 外部から文章を入れられる作りにすると、
「これは買いシグナルです」と書くだけで判断を動かせる。

## 2. 実験22：confidence が「材料の割れ具合」を示している

材料（千鳥化学）：
> 「通期の売上高は過去最高を更新しました。一方で、原材料価格の高騰と販促費の増加により、営業損益は赤字に転落しています。」

| 質問 | 結果 |
|---|---|
| 営業損益は赤字か（事実） | **0.980** ✓ |
| どれくらい前向きか（Score） | **0.780**（conf **0.670**） |

事実は正しく読めている。「過去最高」という強い語にも引きずられず、
前向きさは 0.78 と、中間（1.0）よりやや後ろ向き側に置いた。

### confidence がこれまでで最低

**同じ Score の criteria を使った全実験を並べると、きれいな順序になる。**

| 材料 | score | confidence |
|---|---|---|
| 蒼井フーズ（計画超過。明白に前向き） | 2.000 | **1.000** |
| 榎木商事（増収・減益。やや混在） | 0.95〜0.96 | **0.930** |
| **千鳥化学（過去最高だが赤字。強く対立）** | 0.780 | **0.670** |

**材料の中で良い材料と悪い材料が強く対立しているほど、confidence が下がっている。**

これは実験15の発見（当てはまる選択肢がないと confidence が下がる）とは別の用法。

- **実験15**：選択肢が合っていないことの合図
- **実験22**：材料そのものが割れていることの合図

**どちらも「この判断をそのまま自動で使ってよいか」の判断材料になる。**
decisions.md の「確率で合成し、confidence で分岐する」2段構えが、実際に機能しそうだと分かった。

### C の実験10との比較

同じ千鳥化学のコメントに、Noul で「ポジティブか」と聞いたときは **0.19**（明確に否定寄り）。
Score で3段階を用意すると **0.78**（中間よりやや下）。

D の実験17で見たのと同じ構造。**中間の置き場があれば使い、なければどちらかに倒れる。**

## 3. 実験24：婉曲な言い回しは読み抜けている

材料（紅屋電機）：
> 「当四半期は、想定どおりの厳しい結果となりました。構造改革の効果が数字に表れるまでには、もう少しお時間をいただくことになります。」

| 質問 | 予想 | 結果 |
|---|---|---|
| 業績が悪かったことを認めているか | 1 | **0.930** ✓ |
| 経営陣が結果に満足していることを示しているか | 0 | **0.030** ✓ |

**「想定どおり」という緩衝材に引っかからなかった。** 予想どおり。

C の実験14で、同じコメントを「悲観的／中立／楽観的」で聞いて
Choice が「悲観的」（conf 0.96）、Score が 0.08（conf 0.88）だったのと整合する。

日本の決算コメントは婉曲な表現が多いが、**この程度なら問題にならない。**

## 4. 全体を通して：事実は堅い、評価は動く

| 種類 | 質問 | 結果 |
|---|---|---|
| **事実** | 営業損益は赤字か | 0.980 ✓ |
| **事実** | 新しい事実を伝えているか | 0.060 ✓ |
| **事実** | 業績が悪かったと認めているか | 0.930 ✓ |
| **評価** | 前向きな材料か（主張つきニュース） | 0.710 ← 引っ張られた |
| **評価** | どれくらい前向きか（対立する材料） | 0.780（conf 0.670） |

**ひっかけの材料でも、事実を読む質問は3つとも正しく答えている。**
崩れたのは、評価を聞く質問のほう。

### 設計への示唆

- **事実の抽出は信用してよい。** 表面と中身がずれていても、婉曲でも、主張が混ざっていても読める
- **評価の質問は、事実の質問で守る。** 実験23の `new_fact` のように、
  「そもそもこの材料は判断に値するか」を別に聞いて、コード側で門にする
- **confidence を見る。** 材料が割れているときは下がるので、自動実行を止める合図に使える

## 方針への影響

- **外部から文章を入れられる作りにしない。**（decisions.md の記述に根拠ができた）
- **材料の信頼性を判定する質問を、判断の前に置く。**
  「新しい事実を伝えているか」「意見ではなく事実か」を聞き、コードで門にする。
  → フェーズ2の判断設計に入れる。
- **confidence の使い道が2つに整理できた。**
  1. 当てはまる選択肢がない（実験15）
  2. 材料が割れている（実験22）
  どちらも「自動で実行してよいか」の分岐に使える。
- **判断が割れうる問いには中間の置き場を用意する。**（D・F で重ねて確認）
