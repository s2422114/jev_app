## 1. 実験9：広い問いは情報を壊した（最重要）

| ケース | 結果 |
|---|---|
| broad「この先上がりそうですか？」 | **0.580** |
| positive「`決算コメント`はポジティブですか？」 | 0.980 |
| temporary「増益は一時的なものですか？」 | 0.280 |
| priced_in「`株価.発表前の動き`に反映されていますか？」 | 0.390 |

分解した3つは、**すべて買いに有利な方向**を指している。

- 内容は極めて前向き（0.98）
- 一時的な要因ではない（0.28 と低い）
- まだ織り込まれていない（0.39 と低い）

この3つを合成すれば、はっきりした結論が出せる。
ところが broad は 0.580 で、**ほぼ「どちらとも言えない」**。判断材料として使えない。

**学び：広い問いは、材料が揃っていても答えを 0.5 付近に潰す。**
公式が「分解はこのガイドで最も重要な概念」としている理由が、数字で見えた。

### なぜ broad が 0.58 になったか

質問が「この先上がりそうか」という**予測**だったため。
分解した3問は渡した材料を読む問いだが、broad は材料に書かれていない未来を聞いている。
Jev は state を評価するモデルなので、答えようがない。

質問を書く時点で「これは予測を聞いていないか」を確かめる必要がある。
予測を聞いた瞬間、Jev の答えは意味を失う。

### 補足：priced_in は B とほぼ同じ値

B の実験7で、同じ大湖精機・同じ「発表前に急上昇」に対して 0.46 だった。
今回、窓を明示する形に書き直しても 0.39 で、大きく変わっていない。
**窓の曖昧さを消しても、Jev はこの材料を「織り込み済み」とは読まない。**
B のメモに書いた「事前の予想を state に入れる」方針の必要性が、さらに裏付けられた。

## 2. 実験15：逃げ道がないと、間違えたうえに気づけない

| ケース | 結果 | 正解 |
|---|---|---|
| M&A・該当なしなし | M&A（conf 1.000） | ✓ |
| M&A・該当なしあり | M&A（conf 1.000） | ✓ |
| 本社移転・該当なしなし | **人事（conf 0.630）** | ✗ |
| 本社移転・該当なしあり | **該当なし（conf 1.000）** | ✓ |

**3つのことが同時に分かった。**

1. **逃げ道がないと、無理やり間違った分類に入れる。** 本社移転を「人事」と答えた。
   jaggedness の「Choice は相対的な問い」の実例。全部外れていても、一番マシなものが選ばれる。
2. **ただし confidence が落ちる（0.63）。** 他の3ケースは 1.000。
   **confidence が、当てはまる選択肢がないことの合図になっている。**
3. **逃げ道を足しても、正しく分類できるケースは壊れない。** M&A は両方とも 1.000 のまま。

**方針：Choice には必ず「該当なし」を入れる。** 入れない理由がない。
入れられない場合は、confidence の低下を見て弾く。

## 3. 実験10：criteria は効いたが、方向はもともと合っていた

| ケース | 予想 | 結果 |
|---|---|---|
| criteria なし | 0.5 | **0.190** |
| criteria あり | 0.1 | 0.060 |

criteria なしの時点で、Jev はすでに 0.19 と答えている。
「売上は過去最高だが営業赤字」に対して、**何も指示しなくても利益を重く見ていた**。

予想は 0.5（どちらを重視するか分からないので真ん中）だったが、Jev は迷わなかった。
A・B から続く「こちらが中間に寄せ、Jev がはっきり答える」パターン。

criteria は 0.19 → 0.06 と、判断をさらに強めた。効いてはいる。

### ただし、確かめられていないことがある

**今回の criteria は、Jev の既定の読みと同じ方向だった。**
逆方向（売上を重く見る）の criteria を書いたら、0.19 を 0.8 に動かせるのか。
これが分からないと、「criteria でドメインの規則を伝えられる」とは言い切れない。

本番では、Jev の常識と違う基準を持ち込む場面が出てくる。追試する価値がある。

## 4. 実験11：曖昧な語の本当の危険は、迷わないこと

| ケース | 予想 | 結果 |
|---|---|---|
| vague「企業の調子は良いか」 | 0.4 | **0.350** |
| specific「売上は増収か」 | 1.0 | 0.980 |

予想がよく当たっている。ここまでの結果からずれ方の傾向をつかめてきた証拠。

**重要なのは、vague が 0.5 に寄らなかったこと。**
曖昧な語で聞いても、Jev は困らない。**自分の基準で判断して、はっきりした答えを返す。**

これが危険な理由：

- 0.5 が返れば「この質問はだめだ」と気づける
- 0.35 が返ると、もっともらしいので**そのまま使ってしまう**
- しかしその 0.35 は、こちらが決めていない基準で出た数字

**学び：曖昧な質問の害は「答えが出ないこと」ではなく「気づかないまま他人の基準で答えが出ること」。**

## 5. 実験12・13：今回は数字が揃った（ただし簡単な材料だった）

**実験12（肯定形と否定形）**：positive 0.950 / negative 0.030 → 合計 **0.98**

公式の例では 0.72 + 0.47 = 1.19 と大きくずれていた。今回はほぼ 1。

**実験13（Noul vs Choice）**：noul 0.940 / choice「はい」（conf 1.000）

公式の例では noul 0.22 に対し choice の yes が 0.01 と食い違っていた。今回は両方とも強く「はい」。

### これは公式の警告を否定しない

**どちらも、蒼井フーズの「計画を上回って着地」という、判断が割れない材料だった。**
答えが明白なときは、聞き方を変えても同じ答えになる。当然のこと。

公式の警告が効くのは、**判断が割れる材料**のとき。
同じ実験を千鳥化学のコメント（売上最高だが赤字）でやれば、ずれるかもしれない。

**追試の価値がある。** 閾値を質問ごとに持つ方針の根拠になる。

### 比較の注意

実験13で比べるべきなのは、noul（0.940）と Choice の**「はい」の確率**。
表に出ている conf 1.000 は確率ではないので、そのまま並べられない。
確率は生の JSON に入っているので、そちらを確認する。

## 方針への影響

- **分解は必須。** 実験9で、広い問いが情報を壊すことが数字で出た。コストもほぼ変わらない。
- **質問が予測を聞いていないか確かめる。** 予測を聞くと答えが 0.5 付近に潰れる。
  Jev に聞けるのは、渡した材料について読み取れることだけ。
- **Choice には必ず「該当なし」を入れる。** 入れないと間違った分類に入る。
  入れられない場合は confidence の低下で弾く。
- **曖昧な語を使わない。** 答えが出ないのではなく、こちらが決めていない基準で答えが出る。
- **criteria は効く。** ただし Jev の既定の読みと逆方向でも効くかは未確認。

## 注意点

- 各ケース1回ずつ。実験25（同じリクエストを何度か）で、ぶれの範囲を確認する。
- Choice の予想は、確率ではなく「どのラベルが選ばれるか」と confidence で書くほうが読みやすい。
  今回は選択肢の番号で書かれていた（0＝業績、4＝該当なし）。
- 実験9と10で同じ質問文（「`決算コメント`はポジティブですか？」）を使っている。
  state は違うので実験としては成立するが、結果を読むときは混同しないよう注意。
- 副産物：実験12の positive（0.950）と実験13の noul（0.940）は、同じ state に対する
  「ポジティブか」と「前向きか」。**語を変えてもほぼ同じ答え**だった。
  明白な材料では、語の違いが効かないということ。
