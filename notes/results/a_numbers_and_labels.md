## 予想と大きく違ったもの

### 1. 白馬製薬の ratio と label（予想 0.5 → 結果 0.12 / 0.07）

予想は「多くもないし少なくもないので真ん中」。しかし質問は「普段と比べて**目立って多い**」だった。
1.01倍は目立って多くないので、質問への答えは「いいえ」になり、確率は低くなる。

**学び：Noul の 0.5 は「中くらいの値」ではなく「はいかいいえか分からない」という意味。**
「どちらでもない」は 0.5 ではなく、質問に対しては「いいえ」。
jaggedness の「書いた質問にそのまま答える（literal reading）」の実例。

### 2. 前日比 -2.9% と -3.1%（予想 0.3 / 0.2 → 結果 0.48 / 0.47）

2つの差がほぼない。しかも下落が大きい富士見運輸（-3.1%）のほうがわずかに低い。
Jev は 0.2 ポイントの違いを区別できておらず、どちらも「大幅かどうか分からない」あたりに置いている。

**学び：コード側で決めた -3% という境目は、Jev の中にはない。細かい境目は Jev に任せられない。**

## 予想どおりだったもの

### 3. 実験1の raw は強かった

2つの数値の大小比較は、0.54 の僅差（千鳥化学 880.51 対 879.97）でも 0.97 と正しく出た。
jaggedness を読んで警戒していたほどは崩れなかった。

ただし、今回は「2つの数値を比べるだけ」の単純な形。計算や複数の数値が絡む場合にも通用するとは限らない。

### 4. 実験1の label は raw より弱かった

| 銘柄 | raw | label |
|---|---|---|
| 蒼井フーズ（正解：はい） | 0.98 | 0.68（上昇トレンド） |
| 紅屋電機（正解：いいえ） | 0.02 | 0.24（下降トレンド） |
| 千鳥化学（正解：はい） | 0.97 | 0.41（横ばい） |

向きは予想どおり。蒼井フーズは予想 0.8 に対して 0.68 と、予想以上に下がった。
「上昇トレンド」から「25日線が75日線より上」を読み替える一段（indirection）が効いていると考えられる。
一般に上昇トレンドでも25日線が上とは限らない場面があり（下落に転じた直後など）、
Jev はコード側の判定定義を知らないので、その曖昧さに反応した可能性がある。

## 実験4：confidence は「label か raw か」では決まらなかった

| 銘柄 | raw の confidence | label の confidence |
|---|---|---|
| 榎木商事（label：下落） | 0.80 | 0.75 |
| 富士見運輸（label：大幅下落） | 0.87 | 1.00 |

label が常に高いわけではない。「大幅下落」のように答えそのものの言葉だと 1.00、
「下落」のように幅のある言葉だと、raw よりむしろ下がった。

**学び：confidence を決めていたのは、ラベルの言葉がどれだけはっきりしているか。**

## 方針への影響

- **「計算と境目はコード」は裏付けられた。** 2の結果どおり、細かい境目は Jev に任せられない。
- **「数値は全部ラベルにする」は見直しの余地あり。**
  比較そのものを聞くなら raw のほうが素直だった（3・4）。
  ただし比較はそもそもコードでやる方針なので、本番で Jev に聞くことはない。
  **ラベルは Jev に答えを読み取らせるためではなく、文章を判断するときの文脈として置くもの**、
  という位置づけがよりはっきりした。
- **ラベルの言葉選びが効く。** 「下落」のような幅のある言葉は判断を揺らす。
  境目がはっきり伝わる言葉を選ぶ。
- **質問の言葉も同じ。** 「目立って多い」のような語は文字どおりに読まれる。聞きたいことをそのまま書く。
