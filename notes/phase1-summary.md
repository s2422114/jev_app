# フェーズ1 総括

A〜G の27実験を横断して見えたもの。個別の読み解きは `notes/results/` の7本に残してあり、
このファイルはそれを置き換えるものではない。数字はすべて7本のメモから引いている。

---

## 1. 何をやったか

- **材料**：架空の8銘柄 × 150営業日の終値と出来高、文章22本（すべて日本語と英語の対）、
  銘柄に紐づかない市況記事2本。株価は seed 固定で生成し、狙った形（上昇・下落・横ばい・
  発表前の急上昇・前日比 -2.9%/-3.1%・出来高3.1倍）に作り分けた。
  指標とラベルは JSON に保存せず、コードで計算している。
- **実験**：計画どおり27項目すべてを実施。66ケース、78リクエスト
  （G の実験25で同じリクエストを5回ずつ投げたぶん、ケース数より多い）。
- **モデル**：全実行で `jev-1.13.0`。
- **usage**：入力 36,221 / 出力 2,113 トークン（各メモの合計）。
  ＊ G のメモには「全体で約32,000トークン」とあるが、A〜G の7本を足すと上記になる。
  料金は出力無料・入力がこの量なので、実験全体で 0.01ドル未満。

## 2. 実験をまたいで見えたこと

### 2.1 事実の質問は堅く、評価の質問は動く

これがいちばん太い線で、F と G の両方で独立に出た。

- **事実**：営業赤字か 0.980（F22）、新しい事実を伝えているか 0.060（F23）、
  業績が悪かったと認めているか 0.930（F24）、営業減益か 0.980（G26 の3通りの書き方すべて）。
  表面と中身がずれていても、婉曲でも、書き手の主張が混ざっていても、文体が変わっても読めている。
- **評価**：同じ state で「前向きな材料か」は 0.710 まで押し上げられ（F23）、
  同じ事実を言い換えただけで 0.94 → 0.48 に落ちた（G26）。

**設計上の意味**：Jev に聞くものを「事実の抽出」と「評価」に分け、後者は前者で守る。
F23 では、評価（0.71）だけを見ていたら信じてしまうところを、
事実の質問（0.06）が「この材料は判断に値しない」と教えている。

### 2.2 中間の置き場があれば使い、なければどちらかに倒れる

同じ千鳥化学のコメント（売上は過去最高だが営業赤字）に対して：

| 聞き方 | 結果 | 出どころ |
|---|---|---|
| Noul「ポジティブか」（中間なし） | 0.190（否定寄りに倒れる） | C10 |
| Score 3段階（真ん中に「どちらとも言えない」） | 0.780（conf 0.670） | F22 |

同じことが分類でも起きた。本社移転のニュースを「該当なし」なしの Choice で聞くと
**人事（conf 0.630）**、「該当なし」を足すと **該当なし（conf 1.000）**（C15）。
榎木商事の増収減益も、Score の真ん中が用意されていたので 1 付近に置かれた（D17）。

**設計上の意味**：判断が割れうる問いには、必ず中間か「該当なし」を用意する。
用意しないと、Jev は無理にどちらかへ倒れ、しかもその答えはもっともらしく見える。

### 2.3 confidence には3つの使い道がある

| 何の合図か | 観測 | 出どころ |
|---|---|---|
| 当てはまる選択肢がない | 逃げ道なしで誤分類したとき 0.630（他は 1.000） | C15 |
| 材料そのものが割れている | 明白 1.000 → 混在 0.930 → 強く対立 0.670 | F22 |
| その判断が文体などで揺れている | 言い換え c だけ 0.270（a・b は 0.90 / 0.97） | G26 |

さらに G25 で、**confidence が低いケースほど、同じリクエストを繰り返したときの値も揺れた**
（明白なケースはぶれ 0.00、割れるケースは 0.04）。confidence は「この判断は揺れる」の予告でもある。

**設計上の意味**：decisions.md の「確率で合成し、confidence で分岐する」2段構えは、
3つの別々の事情をまとめて拾える。低い confidence は自動実行に回さない。

### 2.4 質問は安く、state は高い

| 何を足すか | 増分 | 出どころ |
|---|---|---|
| 質問を1問足す | 約 +37トークン | C（exp9 broad 441 → decomposed 515） |
| Choice の選択肢を1つ足す | 約 +10トークン | C15（389 → 399） |
| 他の銘柄を3社足す | +370トークン（1.7倍） | D16（533 → 903） |
| 長文にする | +309トークン（1.5倍） | D17（569 → 878） |
| 3問を1リクエストにまとめる vs 1問ずつ3回 | 636 対 1,468（**2.3倍**） | G27 |

しかも G27 では、まとめて聞いても答えは変わらなかった
（positivity 2.000 / temporary 0.330 は完全一致、priced_in は 0.500 対 0.490 でぶれの範囲）。

**設計上の意味**：質問は惜しまず分解してまとめて投げる。state だけを絞る。
C9 で広い問い1つ（0.580）が分解した3問（0.980 / 0.280 / 0.390）より判断材料にならなかったことと
合わせると、分解しない理由がない。

### 2.5 Jev は質問に書いたことにそのまま答える

予想が外れたケースの多くが、これで説明できる。

- 出来高が平均の1.01倍のとき「**目立って多い**か」→ 0.120。
  「多くも少なくもない」は 0.5 ではなく「いいえ」（A3）。
- 「織り込み済みか」は、発表前の窓と発表後の窓で答えが逆になる。
  質問が `株価.発表前の動き` を名指ししていたので、Jev はその窓で答えた（B7）。
- 「企業の調子は良いか」のような曖昧な語でも 0.5 に逃げず、0.350 とはっきり答える（C11）。

**設計上の意味**：曖昧な質問の害は「答えが出ないこと」ではなく、
**こちらが決めていない基準で、もっともらしい答えが出ること**。
質問文を書き直すことが設計の見直しになる（B7 では「織り込み済みか」を「期待通りか」に
変えることで、株価の判定はコード、文章の比較は Jev、と分担が分かれた）。

### 2.6 予想のずれ方には傾向があった

- **A〜C**：こちらが中間に寄せ、Jev がはっきり答えた。
  白馬製薬 0.5 → 0.120（A）、実験5 の 1.5 → 2.000（B）、実験8 の本業 0.6 → 0.230（B）、
  実験10 の 0.5 → 0.190（C）、実験14 の Choice 0.5 →「悲観的」conf 0.960（C）。
  「例外もあるかもしれない」と含みを残すと、質問に素直に答える Jev とずれる。
- **D**：逆に、こちらが 0（後ろ向き）と決めつけ、Jev が 1 付近（どちらとも言えない）に置いた（D17）。
  違いは Score の真ん中に置き場が用意されていたこと。2.2 と同じ構造。
- **C11 以降は予想が当たるようになった**（vague 0.4 → 0.350）。
  ずれ方の傾向をつかめたぶん、予想の精度が上がっている。

## 4. 個別に印象的だったもの

### 4.1 広い問いは、材料が揃っていても答えを潰す（[C](results/c_question_writing.md)）

分解した3問はすべて買いに有利な方向を指していた（内容は前向き 0.980 /
一時的要因ではない 0.280 / まだ織り込まれていない 0.390）のに、
「この先上がりそうですか？」という広い問いは **0.580**、ほぼ「どちらとも言えない」だった。
質問が予測を聞いていたことも効いている。Jev が答えられるのは、渡した材料から読み取れることだけ。

### 4.2 中身が薄いと分かったうえで、主張に引っ張られた（[F](results/f_traps.md)）

「これは明らかな買いシグナル」と書かれたニュースに対して、
「業績に関する新しい事実を伝えているか」は **0.060**（正しく見抜いている）。
それなのに「前向きな材料か」は **0.710**。
外部から任意の文章を入れられる作りにしない、という方針の根拠になった。

### 4.3 言い換えただけで評価が半分になった（[G](results/g_stability.md)）

同じ事実を3通りの書き方で渡したところ、事実の抽出は3つとも 0.980 で同じなのに、
前向きさは 0.940 / 0.980 / **0.480** と分かれた。confidence も 0.900 / 0.970 / **0.270**。
実際の決算コメントは企業ごとに書き方が違うので、本番で直接効く。

### 4.4 逃げ道がないと、間違えたうえに気づける（[C](results/c_question_writing.md)）

本社移転のニュースを、「該当なし」を入れない Choice で聞くと **人事（conf 0.630）**、
入れると **該当なし（conf 1.000）**。M&A のニュースは選択肢を足しても 1.000 のままで壊れなかった。
間違えたときに confidence が落ちるので、合図としても使える。

### 4.5 言葉を選び直すと、分担まで変わった（[B](results/b_text_and_context.md)）

「織り込み済みか」は、発表前の窓と発表後の窓で答えが逆になる問いだった
（急上昇 0.460 / 横ばい 0.190）。これを「期待通りか」に変えると、
株価が先回りしていたかの判定はコード、決算内容と事前予想の比較は Jev、と自然に分かれる。
質問文を1ファイルに集約する方針には、書き方を揃える以上の意味がありそう。

## 5. 確認できていないこと

総括として断定していないもの。方針を立てるときは、ここを前提にする。

- **天井に張り付いたケースは「動かなかった」証明にならない。**
  実験5（文脈を足してもぶれない）、実験16・18（他銘柄やノイズを足しても動かない）は、
  4つとも 2.000 / conf 1.000 だった。動かなかったのか、天井で差が見えないだけなのかは
  **未確認**。jaggedness の「無関係な情報が増えると精度が落ちる」を否定する結果ではない。
- **言語差は1材料・1回の観察。** 日本語が英語より不利に見えなかった、までしか言えない。
  英語版は日本語版の訳なので、訳の質も混ざっている。本番の材料で再確認が要る（E19）。
- **G26 で書き方 c だけ動いた理由は推測。** 短さ・語順・語の中立さのどれが効いたかは未確認。
- **F23 の 0.710 が書き手の主張によるものかは未確認。** 主張を抜いた文との比較をしていない。
- **criteria で Jev の既定の読みを逆転できるかは未確認。**
  C10 で criteria は効いた（0.190 → 0.060）が、方向はもともと Jev の読みと同じだった。
- **ぶれの幅は各5回の観測。** 回数を増やせば、より外れた値が出る可能性はある。
- **実験12・13（否定形、Noul vs Choice）は判断が割れない材料で試した。**
  今回ずれなかったこと（0.950 + 0.030 = 0.98）は、公式の警告を否定しない。
