# フェーズ1 実験計画

Jev の得手不得手を、株の題材で確かめるための実験の一覧。
全項目を実施する。あわせて、実験ごとの使用量（usage）も測る。

## 共通のルール

- **材料は1か所にまとめる。** 架空の銘柄ごとに、株価の生の数値と文章（決算コメントやニュース）を持つ材料ファイルを作り、実験ごとに必要な部分だけを取り出して state を組み立てる。比べたい条件以外を揃えるため。
- **銘柄は架空にする。** 実在企業だと、Jev が学習時の知識で答えを寄せる可能性があり、何に反応したのか分からなくなる。
- **指標とラベルはコードで計算する。** ラベルの境目（何%から「大幅」か）もコード側で決める。
- **state は入れ子の JSON にする。** 質問の中で `` `stock.comment` `` のようにバッククォートで場所を指す（公式推奨）。
- **ケースごとに先に予想を書く。** 実行前に書く。「予想と違った」を残すため。
- **結果と usage を記録する。** usage はレスポンスの `usage`（入力・出力トークン数）から取る。コンソールの集計は遅れることがある。
- **「予想と違った」ものは notes/ に残す。** 数字だけでなく、なぜ違ったと思うかも書く。ポートフォリオで Jev の得手不得手を語る材料にする。

## 分担

- **ユーザー**：実験の選択、各ケースの予想、C（質問の書き方、9〜15）の質問文、結果の解釈
- **Claude Code**：材料ファイル、C 以外の state と質問文、実行、結果と usage の記録、レポートのテンプレート（1回だけ）

## A. 数値とラベル

1. **比較が要る数値**：25日線と75日線の値を生で渡して「25日線は75日線より上か」と聞く vs 「上昇トレンド」のラベル付きで同じことを聞く。jaggedness の「数値の比較が苦手」が実際にどれくらいか。
2. **境目の近く**：前日比 -2.9% と -3.1% をそれぞれ生で渡し「大幅下落か」と聞く。Jev の「大幅」の感覚が、自分の決めたい境目とずれるか。
3. **表し方の違い**：出来高を「3,100,000株」「平均の3.1倍」「急増」の3通りで渡す。同じ事実でも、どの表し方が一番安定するか。
4. **数値を渡したときの confidence**：同じ判断を生の数値とラベルで聞いて confidence を比べる。数値だと迷いが増えるのか。

## B. 文章と文脈の組み合わせ

5. **文脈を足しても答えがぶれないか**：決算コメントだけで「どれくらい前向きか」を Score で聞く vs 同じコメントにトレンドのラベルを足して同じことを聞く。
6. **整合性**：コメントとトレンドが一致するケース（好決算＋上昇）と矛盾するケース（好決算＋下落）で「このコメントは株価の動きと整合しているか」。本アプリの肝になりそうな判断。
7. **織り込み済みか**：同じ好決算のコメントに「発表前から急上昇していた」「横ばいだった」のラベルをそれぞれ付けて聞く。
8. **一時的か恒常的か**：「特別利益による増益」と「本業の伸びによる増益」で、一時的な要因かを聞く。

## C. 質問の書き方（質問文はユーザーが書く）

9. **広い問い vs 分解**：「買うべきか」1問 vs 「業績は前向きか」「一時的要因か」「織り込み済みか」の3問を合成。分解の効果。
10. **criteria の有無**：同じ Noul を、criteria なしと、true／false の説明と例を書いたものとで比べる。
11. **曖昧な語 vs 具体的な語**：「業績は好調か」vs「前年同期と比べて増益か」。
12. **否定形**：「前向きか」と「後ろ向きか」を両方聞いて、足して1になるか。
13. **Noul vs Choice**：「前向きか」を Noul で聞く vs はい／いいえの Choice で聞く。
14. **Choice vs Score**：悲観的／中立／楽観的を Choice と Score の両方で聞く。
15. **「該当なし」の有無**：ニュースの種類を Choice で聞くとき、「どれにも当てはまらない」を入れる場合と入れない場合。

## D. state の量

16. **他の銘柄を混ぜる**：対象の銘柄だけ vs 他の銘柄のデータも一緒に渡す。
17. **短文 vs 長文**：コメント1文 vs 決算短信のような長い文章から同じことを聞く。
18. **無関係な情報を混ぜる**：他社のニュースや市況全般の話を足す。

## E. 言語

19. **英語 vs 日本語**：同じ state と質問を両方で投げて、答えと confidence を比べる。（未決の論点4に直結）
20. **混在**：state は日本語、質問は英語。
21. **金融用語**：「上方修正」「減損」「特別損失」「下方修正」など、日本語の専門用語を正しく読めるか。

## F. ひっかけ

22. **表面と中身のずれ**：「売上は過去最高。ただし営業赤字に転落」のような文。
23. **自己主張する文**：「これは明らかな買いシグナルです」と書かれた文章。
24. **皮肉や婉曲**：「想定どおりの厳しい結果となった」のような言い回し。

## G. 安定性

25. **同じリクエストを何度か**：値が変わるか。
26. **言い換え**：同じ内容を違う文で書いて、答えが揃うか。
27. **まとめて聞く vs 1問ずつ**：答えが変わらないか（公式の「並列で互いに影響しない」の確認）。
